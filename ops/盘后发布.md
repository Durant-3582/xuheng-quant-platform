# 盘后发布全量行情

在保存有序衡全量历史库的 Mac 上，双击 **盘后更新行情.command**。也可以从 `xuheng-independent` 目录使用已安装 `requirements.txt` 的 Python 执行以下命令。

```sh
python ops/publish_after_close.py
```

默认按上海日期查询 Tushare 的交易日历和已公布收盘数据。线上已覆盖该交易日时直接结束。新交易日复用 `ingest/build.py` 增量更新全量数据库，随后将通过逐项校验的数据包保存在 `.private/cloud-releases/YYYYMMDD/`。首次迁移已准备好的同日版本可直接复用 `.private/cloud-release/`。

入口读取环境变量 `TUSHARE_TOKEN` 或本机 `.private/tushare-token`。存储写入凭据优先取 `XUHENG_ARCHIVE_WRITE_KEY`。未设置时，入口在本机用 Tushare Token 为当前存储单独派生写入凭据，并通过环境变量传给上传子进程。原始 Token 只用于 Tushare。

上传器依次校验远端的所有数据包和索引，再写入 `/v1/current`，并回读核对交易日、索引及日线数。看到 `ACTIVE` 表示新版本已生效。中断后重新执行同一命令即可续传，已校验的远端对象会跳过。已发布的历史版本继续保存在服务端。可用 `--until YYYYMMDD` 指定查询上限，用 `--rpm N` 设置 Tushare 每分钟的查询数。

单独运行 `ops/upload_private.py 版本目录 服务地址` 可预上传一个版本，加 `--activate` 会在校验后切换。它支持 `XUHENG_ARCHIVE_WRITE_KEY` 或终端中的隐藏输入。
