# 盘后发布全量行情

## 自动更新

GitHub Actions 每天按北京时间 19:17 和 22:17 检查交易日历。后一次检查可补取较迟到齐的行情。休市时也会检查上一交易日有无漏更。任务在 GitHub 的 Linux 运行器上执行，访客和管理员均可关机。GitHub 队列繁忙时实际启动可能延后。

行情任务成功后，同一次运行接着核对研究库，更新已披露财报、选股因子、市场宽度和申万 31 个一级行业。行情任务失败时，研究库保留上次完整版本。当天 15:00 前手动补跑时，默认只检查前一日及以前已经收盘的交易日。

新闻独立于交易日历，按北京时间每小时 09 分和 39 分采集东方财富最近 200 条快讯，周末照常。即使标题没有变化，成功核验也会更新采集时间。抓取失败或来源返回旧数据时保留已有样本。[新闻任务记录](https://github.com/Durant-3582/xuheng-quant-platform/actions/workflows/news.yml)

GitHub 的 `xuheng-cloud-clock` 发布环境另设 30 分钟等待。每轮结束会在云端安排下一轮，等待期间不占用运行器。它检查新闻和盘后两份运行记录，已有成功或仍在运行的批次会跳过，单个时段最多尝试两次。新闻发布前也会检查本时段的实际采集时间。若环境计时被移除，程序会停止接续并报错。需要重新启动时，可在[云端更新补跑](https://github.com/Durant-3582/xuheng-quant-platform/actions/workflows/cloud-clock.yml)点击一次 **Run workflow**，时间输入留空。停用该工作流即可停止这项补跑。

定时任务读取仓库 Actions secret `TUSHARE_TOKEN`。它凭已发布的索引校验并恢复证券历史、历史排名和开盘成交限制，向 Tushare 补入缺失交易日。若新发现的证券或代码映射影响历史排名，使用接口重新核算。任务只在核验成功后切换正式库，另一批次同时发布时由存储服务检查版本。原始限价表和历史 PB 明细只在取数机器的临时目录计算。

在仓库的 [Actions 运行记录](https://github.com/Durant-3582/xuheng-quant-platform/actions/workflows/after-close.yml) 可以查看交易日和发布结果，也可点 **Run workflow** 立即运行。勾选核验基线，即便没有新交易日，也会在全新的云端机器恢复并验证已有历史。公共仓库连续 60 天没有活动时，GitHub 可能停用定时运行，可在该页面重新启用。[GitHub 定时任务说明](https://docs.github.com/en/actions/reference/workflows-and-actions/events-that-trigger-workflows#schedule)。

## 本机补发

在保存有序衡全量历史库的 Mac 上，双击 **盘后更新行情.command**。也可以从 `xuheng-independent` 目录使用已安装 `requirements.txt` 的 Python 执行以下命令。

```sh
python ops/publish_after_close.py
```

默认按上海日期查询 Tushare 的交易日历和已公布收盘数据。线上已覆盖该交易日时直接结束。新交易日复用 `ingest/build.py` 增量更新全量数据库，随后将通过逐项校验的数据包保存在 `.private/cloud-releases/YYYYMMDD/`。首次迁移已准备好的同日版本可直接复用 `.private/cloud-release/`。

入口读取环境变量 `TUSHARE_TOKEN` 或本机 `.private/tushare-token`。存储写入凭据优先取 `XUHENG_ARCHIVE_WRITE_KEY`。未设置时，入口在本机用 Tushare Token 为当前存储单独派生写入凭据，并通过环境变量传给上传子进程。原始 Token 只用于 Tushare。

上传器依次校验远端的所有数据包和索引，再写入 `/v1/current`，并回读核对交易日、索引及日线数。看到 `ACTIVE` 表示新版本已生效。中断后重新执行同一命令即可续传，已校验的远端对象会跳过。已发布的历史版本继续保存在服务端。可用 `--until YYYYMMDD` 指定查询上限，用 `--rpm N` 设置 Tushare 每分钟的查询数。

单独运行 `ops/upload_private.py 版本目录 服务地址` 可预上传一个版本，加 `--activate` 会在校验后切换。它支持 `XUHENG_ARCHIVE_WRITE_KEY` 或终端中的隐藏输入。
