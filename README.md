# 序衡 · A 股投研

独立的 Streamlit 课程平台，使用 Tushare Pro 收盘数据。原网站只作功能对照；访客查行情、筛因子、跑策略或组合回测时，从本项目的行情库读取。股票包括存续及有记录的退市 A 股，申请不到或无记录的指数在数据覆盖页区分显示。

| 功能 | 使用方法 |
| --- | --- |
| 市场总览 | 看收盘涨跌、交易所宽度、行业等权表现；在页尾查某个标的的真实历史范围。 |
| 指数中心 | 按名称或代码选指数，可选第二个指数。叠图按共同交易日起点归一化。可查截至指定日期已公布的成分和权重。 |
| 个股研究 | 查看日线、选择显示区间、导出当前个股区间、比较 120 个配对日收益计算的滚动 Beta，并查最近已披露的财报。 |
| 因子选股 | 按市场、行业和因子筛选；动量、低波动支持查看下一期分组收益，亦可带入策略回测。 |
| 策略回测 | 在所选历史区间使用月末信号，从下个交易日开盘建仓，比较等权策略和市场基准。 |
| 组合表现 | 默认做区间回测。可用动量、低波动、短期反转、低 PB，或自己增删股票；支持手动、等权及 TB 配权，按日数自定义调仓。另一页签比较 2–8 组参数，先在样本内排名，锁定后才能执行样本外。 |

**先在本机打开：** 安装 Python 3.12 或更新版本及相应依赖，配置 Token 和独立课程口令后，双击项目中的“打开独立版.command”。正式行情库尚未生成时，有验收样本才会显示样本，页面标明范围。验收样本和正式行情库不能混在一起做排名。

```sh
python -m pip install -r requirements.txt
python scripts/configure_token.py
python scripts/create_access.py
python ingest/build.py
streamlit run streamlit_app.py
```

**数据更新：** `ingest/build.py` 确认交易所日历及 Tushare 已发布的最近收盘，从 `daily`、`index_daily`、`daily_basic`、`stk_limit` 等接口取数；已有全库时按新增交易日增量更新，再重算研究分片。完整目录校验成功才切换 `manifest.json`。生产调度应在收盘后运行此命令；是否已配置自动定时任务与是否有可运行的脚本是两回事。

**数据与代码分开：** 公开仓库不包含 Tushare Token、课程口令、用户持仓、付费原始数据或数据库分片。服务端读取本机配置或托管平台 Secrets；访问口令只用 SHA-256 校验。可配置本机行情库、私有只读归档或在托管平台从 Tushare 初始化有明确范围的开发样本。没有有效行情库时页面不编造任何行情。Streamlit 本机服务只监听回环地址；提交给老师使用的是另行部署的浏览器课程入口。

**口径：** 程序按设定费率扣费。无开盘报价不交易；有官方盘前限价时按对应方向判断能否成交，其余用历史常见涨跌幅作近似。缺失收盘报价沿用末次估值，退市残余单独披露。月度净值的回撤无法反映全部月内波动。TB 根据正超额截距与残差方差的比值分配只做多的主动权重，缺少可用估计时留现金。指数价格回溯记录与发布后的可投资比较区分处理。不模拟逐笔撮合和成交量容量。

**核验：** `checks/check_finance.py` 核对手算收益、交易约束、月度指标、Beta 和样本内外边界。`checks/check_ui.py` 操作六个页面、自定义交易日、权重、参数冻结等；两项测试均可使用本地真实数据、断开外部 API 执行。
