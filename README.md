# 序衡 · A 股投研

独立的 Streamlit 课程平台，使用 Tushare Pro 收盘数据。原网站只作功能对照；访客查行情、筛因子、跑策略或组合回测时，从本项目的行情库读取。股票包括存续及有记录的退市 A 股，申请不到或无记录的指数在数据覆盖页区分显示。

| 功能 | 使用方法 |
| --- | --- |
| 市场总览 | 查看涨跌家数及行业等权表现。从「行业表现 → 查看行业轮动」打开 31 个申万一级行业的价格分位、动量排名和月度轮动回测。结果包含行业等权基准、调仓日、费用和官方报价缺失日期。 |
| 新闻情绪 | 查看东方财富最近最多 200 条快讯的市场情绪、小时变化、行业热度及正负面标题。可按股票名称或代码查报道，点击标题打开原文。 |
| 指数中心 | 按名称或代码选指数，可选第二个指数。叠图按共同交易日起点归一化。可查截至指定日期已公布的成分和权重。 |
| 个股研究 | 查看历史日线、含依据的个股诊断和滚动 Beta。「财务披露」展示近 12 个已披露报告期的趋势和明细。「按财务条件筛选」可指定报告期、市场、ROE 下限及负债率上限。点入结果可核对个股原值和公告日。 |
| 因子选股 | 默认按单因子排序，可保存单因子规则。「多因子选股」组合动量、低波、PB、年报 ROE、PE 和换手率，可逐股查看分项贡献。「因子检验」可带入配分及市场，对照逐月 Rank IC、逐年结果和五组下期收益，还可检验信号延续性、比较六个因子的秩相关。 |
| 策略回测 | 在所选历史区间使用月末信号，从下个交易日开盘建仓，比较等权策略和市场基准。 |
| 组合表现 | 默认做区间回测。可用动量、低波动、短期反转、低 PB，或自己增删股票；支持手动、等权及 TB 配权，按日数自定义调仓。另一页签比较 2–8 组参数，先在样本内排名，锁定后才能执行样本外。 |

**先在本机打开：** 安装 Python 3.12 或更新版本及相应依赖，配置 Token 和独立课程口令后，双击项目中的“打开独立版.command”。正式行情库尚未生成时，有验收样本才会显示样本，页面标明范围。验收样本和正式行情库不能混在一起做排名。

```sh
python -m pip install -r requirements.txt
python scripts/configure_token.py
python scripts/create_access.py
python ingest/build.py
streamlit run streamlit_app.py
```

**数据更新**　云端盘后任务每天按北京时间 19:17 和 22:17 检查交易日历。线上已是最新交易日会直接结束。需要更新时，它从正式库读取已归档的历史，通过 Tushare 补入新行情、估值和限价，再校验和发布。管理员也可以从本机运行 `python ops/publish_after_close.py`。[查看运行记录](https://github.com/Durant-3582/xuheng-quant-platform/actions/workflows/after-close.yml)。

行情任务成功后，研究库任务补录 Tushare 财报公告、月末估值和申万官方指数日线。股价、财务报告和研究数据保存在项目的私有行情存储中，`study-data` 分支只发布版本索引。报告按公告日进入历史样本，同一公告日出现冲突的字段保留为空。行业回测从申万 2021 版行业指数启用后计算。[研究数据更新记录](https://github.com/Durant-3582/xuheng-quant-platform/actions/workflows/studies.yml)

**公开课程入口**　访客在普通浏览器打开[序衡](https://xuheng-quant-lab-3582.streamlit.app/)即可使用。Streamlit Community Cloud 直接运行 GitHub 仓库根目录的 `streamlit_app.py`。查历史、筛选和回测按需读取本项目归档的交易数据。点击查询最新日线时，服务器直接调用 Tushare。服务器可以在 Tushare 暂时不可用时继续提供已归档的数据。

新闻任务每小时第 9、39 分钟计划运行。它使用现有行情库的股票名称和代码匹配新闻，在独立的 `news-data` 分支发布标题、原文编号及计算结果。页面共享五分钟缓存，「刷新新闻」向东方财富重新取样，30 秒内同类手动请求共用一次结果。新闻按北京时间显示，抓取失败会保留最近一次有效样本。情绪词表与行业热度参照[衡策的计算口径](https://github.com/Blockpig1911/hengce-quant/blob/fbe153fe63e912c8cf76a8f9243412f49cd30e53/core/news.py)。

**口径：** 程序按设定费率扣费。无开盘报价不交易；有官方盘前限价时按对应方向判断能否成交，其余用历史常见涨跌幅作近似。缺失收盘报价沿用末次估值，退市残余单独披露。月度净值的回撤无法反映全部月内波动。TB 根据正超额截距与残差方差的比值分配只做多的主动权重，缺少可用估计时留现金。指数价格回溯记录与发布后的可投资比较区分处理。不模拟逐笔撮合和成交量容量。

**核验**　`checks/check_finance.py` 核对交易、费用、Beta 和样本边界。`checks/check_ui.py` 通过实际 Streamlit 入口检验消息往返与七栏导航。`checks/check_news.py` 检验快讯评分、股票匹配和来源失败后的恢复。`checks/check_controls.py` 和 `checks/check_research_ui.py` 检验组合锁定、不同调仓方式及图表数据，默认使用本地验收库，可断开外部 API 运行。
